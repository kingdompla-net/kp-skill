# 플러그인 README 작성 기준

이 기준은 `kp-skill` 저장소의 각 플러그인 `README.ko.md`와 `README.md`를 일관되게 작성하는 방법을 정합니다. 현재 `kp-app-skill`, `kp-api-skill`, `kp-skill-manager` README에서 공통으로 사용한 제목·버전·소개·Skill 표·설치·사용 구성을 바탕으로 합니다.

## 파일과 언어

- 각 플러그인에는 `README.ko.md`와 `README.md`를 함께 둡니다.
- 두 파일의 목적, 표의 행과 열, 섹션 순서, 설치 명령과 의미를 맞춥니다. 한국어판에는 한국어 설명을, 영어판에는 같은 내용을 영어로 씁니다.
- 한국어판의 설명 문장은 존댓말로 작성합니다. 고유명사, Skill 이름, 코드, 경로, 명령, API 필드명은 필요한 경우 원문 표기를 유지합니다.
- 플러그인 디렉터리를 기준으로 Skill 문서에 상대 링크를 걸고, 두 README 모두에서 링크가 유효한지 검사합니다.

## 필수 첫 화면 구성

두 파일은 같은 순서로 다음 내용을 배치합니다.

1. 플러그인의 사용자용 제목을 `#`으로 씁니다. 한국어판과 영어판의 제목은 해당 언어에 맞춥니다.
2. 다음 줄에 플러그인 버전을 `버전: x.y.z` 또는 `Version: x.y.z` 형식으로 표시합니다.
3. 플러그인이 제공하는 결과와 대상 사용 상황을 한 문장으로 설명합니다.
4. 모든 제공 Skill을 아래 네 열 표에 한 행씩 기록합니다.

한국어판:

```markdown
| Skill | 버전 | 언제 사용하나 | 역할 |
| --- | --- | --- | --- |
| [`kp-<domain>-<action>`](skills/kp-<domain>-<action>/SKILL.md) | `1.0.0` | <실제 사용 시점> | <Skill이 제공하는 결과와 경계> |
```

영어판:

```markdown
| Skill | Version | When to use | Purpose |
| --- | --- | --- | --- |
| [`kp-<domain>-<action>`](skills/kp-<domain>-<action>/SKILL.md) | `1.0.0` | <When the user needs it> | <Result and responsibility> |
```

표의 Skill 행 순서는 두 언어판에서 같아야 합니다. Skill별 버전은 각 `SKILL.md` frontmatter의 `metadata.version`과 일치시킵니다. 표 설명에는 실제 역할과 주요 적용 조건만 쓰고, 본문 전체를 반복하지 않습니다.

## 선택 섹션

Skill 표 다음에는 해당 플러그인 사용자에게 필요한 설명만 추가합니다. 이미 세 플러그인에서 쓰는 범주는 다음과 같습니다.

- 초기화 후 생성되는 결과, 구조 선택 기준, 지원 환경을 설명합니다.
- Preview와 live 배포처럼 환경별로 다른 승인·검증 절차를 구분합니다.
- 인증 주체, 권한, 비밀 정보의 위치와 사용자의 수동 조치가 필요한 조건을 안내합니다.
- manager·credential 필수 Skill의 자동 설치와 사용 전·후 안내, 그 밖의 선택 Skill을 추가 설치할 때의 동의 절차를 설명합니다.

선택 섹션의 제목과 순서는 두 언어판에서 대응시킵니다. 플러그인과 무관한 상세 절차는 README에 복사하지 말고 담당 Skill이나 reference에 두고 링크합니다.

## 설치 및 사용 섹션

- 사용자 범위와 프로젝트 범위를 구분하고 기본 범위가 프로젝트 로컬이면 이를 분명히 밝힙니다.
- 설치 예시는 실제로 복사해 실행할 수 있는 명령이어야 합니다. 경로, agent, `--global` 사용 여부가 설명과 일치해야 합니다.
- `kp-skill-manager`가 필요한 경우 누락된 전체 세트를 프로젝트 로컬로 자동 설치하고 작업 전·후에 사용자에게 알리는 절차를 씁니다. 설치가 실패했을 때 의존 작업을 진행하지 않는 기준도 적습니다.
- 설치 안내는 한 묶음으로 배치하고 `## 설치` / `## Install`을 기본 제목으로 사용합니다. 새 저장소 초기화와 기존 저장소 설치가 다르면 그 아래 하위 제목으로 구분합니다.
- Skill 표에는 각 Skill의 사용 시점과 역할을 짧게 적습니다. 표만으로 호출 흐름이 충분하지 않으면 `## 사용` / `## Use` 섹션을 추가하고 문서 마지막 주요 섹션으로 둡니다.
- 기존 README를 이 기준으로 재구성하는 일은 별도 요청되거나 해당 문서의 기능 변경을 설명하는 데 꼭 필요할 때만 진행합니다.

## 버전 정합성

플러그인 버전은 `<plugin>/.claude-plugin/plugin.json`, 플러그인 README 두 언어판, 루트 `.claude-plugin/marketplace.json`, 루트 README 두 언어판에서 일치시킵니다. 개별 Skill 버전은 `SKILL.md`가 정본이며, Skill 표의 버전만 해당 Skill과 일치시킵니다. 플러그인 버전과 Skill 버전은 서로 독립적이므로 같은 번호로 억지로 맞추지 않습니다.

## 완료 전 검사

- 양쪽 README에서 플러그인 제목·버전·Skill 행·설치 방법·사용 순서가 대응하는지 확인합니다.
- 모든 상대 링크와 코드 예시의 파일 경로가 실제로 존재하는지 확인합니다.
- 플러그인 버전과 각 Skill 버전이 manifest 및 `metadata.version`과 일치하는지 대조합니다.
- 한국어 설명이 존댓말인지, 문서의 사용자가 확인해야 할 승인 경계가 모호하지 않은지 읽어봅니다.
