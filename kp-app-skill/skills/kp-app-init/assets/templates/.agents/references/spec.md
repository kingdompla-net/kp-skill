# 프로젝트 도구 명세

이 문서는 이 저장소에서 실제 사용하는 프레임워크, 라이브러리, 개발 도구, 실행 환경의 기준입니다. 모든 작업자는 도구를 추가·교체·업그레이드하기 전에 이 명세와 manifest, lockfile, 설정 파일을 함께 확인합니다. 변경 후에는 선언 범위와 잠금 버전을 각각 갱신하고 이 문서도 실제 상태에 맞게 수정합니다.

## 실행 환경

| 항목          | 프로젝트 선언·고정       | 확인된 실행 환경                       | 기준·출처                                                            |
| ------------- | ------------------------ | -------------------------------------- | -------------------------------------------------------------------- |
| Node.js       | {고정 버전 또는 미고정}  | {검증에 사용한 버전, 미확인 시 미확인} | {`.nvmrc`, `.node-version`, `.tool-versions`, `engines.node`, CI 등} |
| 패키지 관리자 | {이름·버전 또는 미고정}  | {검증에 사용한 이름·버전}              | {lockfile 이름·버전과 설정 출처}                                     |
| 외부 CLI      | {프로젝트 pin 또는 없음} | {확인한 실행 파일·버전 또는 미확인}    | {설치 범위와 실행 명령}                                              |

## 도구와 의존성

| 영역     | 도구            | manifest 선언 범위           | lockfile 버전              | 역할·실제 사용                       |
| -------- | --------------- | ---------------------------- | -------------------------- | ------------------------------------ |
| {예: UI} | {패키지·도구명} | {정확한 선언 또는 해당 없음} | {잠금 버전 또는 해당 없음} | {소스·스크립트·설정에서 확인한 용도} |

## 명령과 검증 범위

| 작업   | 명령                  | 결과물·범위              |
| ------ | --------------------- | ------------------------ |
| 개발   | {실제 명령}           | {실제 동작}              |
| 빌드   | {실제 명령}           | {출력 경로·환경}         |
| 린트   | {실제 명령 또는 없음} | {실제 검사 범위}         |
| 서식   | {실제 명령 또는 없음} | {실제 검사·정리 도구}    |
| 테스트 | {실제 명령 또는 없음} | {실제 프레임워크와 범위} |

## 버전 해석

manifest 범위와 lockfile 버전은 다른 값입니다. manifest는 허용되는 버전을 선언하고, lockfile은 재현 설치에 사용할 정확한 버전을 고정합니다. 잠금 버전이 선언 범위에 들어가고 lockfile의 루트 명세가 manifest와 일치하면 서로 달라도 정상입니다. Node.js 실행 버전과 `@types/node` 선언 버전도 서로 구분합니다.
