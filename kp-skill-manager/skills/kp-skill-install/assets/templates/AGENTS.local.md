# 프로젝트 로컬 설정

이 파일은 현재 프로젝트에서 Skill 작업에 필요한 비밀이 아닌 계정·환경 설정을 기록합니다. 프로젝트 루트에 두고 Git에서 무시하며, 원본 템플릿에는 사용자 값을 기록하지 않습니다.

## 추가 비밀 아닌 환경 설정

| 변수 또는 설정 이름 | 환경 | 값 | 사용 위치와 목적 |
| --- | --- | --- | --- |
| {필요한 경우에만 설정합니다.} | {로컬/DEV/PRD} | {비밀이 아닌 값} | {프로젝트 파일과 사용 목적} |

## 계정 식별 정보

| 서비스 | 환경 | 계정 또는 principal | 사용 목적 |
| --- | --- | --- | --- |
| {필요한 경우에만 설정합니다.} | {로컬/DEV/PRD} | {이메일·계정 이름 등 비밀이 아닌 식별 정보} | {필요한 작업} |

## 로컬 보안 저장소 참조

실제 비밀번호, API key, token, private key, 인증서 또는 service account JSON은 이 파일에 넣지 않습니다. API request credential은 `kp-credential`에서 관리하고, 아래에는 값이 아닌 항목 라벨과 사용 범위만 적습니다.

| 서비스·용도 | 환경 | OS 자격 증명 저장소 항목 라벨 | 승인된 사용 범위 |
| --- | --- | --- | --- |
| {필요한 경우에만 설정합니다.} | {로컬/DEV/PRD} | {kp-skill/<저장소>/<환경>/<용도>} | {HTTPS origin·경로·method·header} |
